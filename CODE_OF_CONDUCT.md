# Code of conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent to people. Assume the person on the other side is
trying to build something and ran into a wall. Technical disagreement is
welcome and expected; contempt is not.

Report unacceptable behaviour to the repository owner through a GitHub
private message or a security advisory. Reports are handled in
confidence.
